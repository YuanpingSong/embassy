## Binding

the wrong `this-mac` default; for the single-machine daily case that
became pure friction (a file to hand-write before `embassy serve`
starts). The fix for a wrong default is a right default, not none.

**Deliverable** (base = emb-105 head):
- `loadGatewayNodeInventory`: on ENOENT of the state dir or the file,
  return an ATTESTED default inventory `{ host: os.hostname()
  short-name lower-cased, validated against HOST_TOKEN, fallback
  "localhost"; nodes: [] }` — it MUST go through `attest()` or the
  Claude/Codex providers refuse to construct. Present-but-unreadable
  still refuses (keep the emb-95 ENOENT/EPERM split); a present file
  is parsed exactly as today (multi-node unchanged).

  `store.ts` claimable-empty (a state dir with only nodes.json) and
  the recovery copy ("keep nodes.json" → "nodes.json, if you use
  federation, is untouched").
- Boot cleanup (emb-100 F9): if `gateway-dashboard.html` /
  `gateway-dashboard.zh-CN.html` exist in the state dir (owned,
  mode 0600, regular files), unlink them once and record an activity;
  cutover runbook line.
- Tests: absent dir → default host = hostname; absent file → same;
  hostname failing HOST_TOKEN → "localhost"; unreadable file (EACCES)
  → still refuses with the classified code; present file → parsed
  unchanged; stale dashboard files removed at boot and never
  recreated. Docs: README quickstart step 1 loses the nodes.json
