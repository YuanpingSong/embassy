## Binding

**Why**: emb-99 charter. Keeping `embassy serve` alive in a terminal
(or nohup) and restarting it by hand after every wedge was the
single largest source of operational friction this window. In-
process auto-spawn from `send` was rejected by the audit (host-lock
contention between racing sends, control-socket creation window,
readiness signalled only on the foreground process's stdout, no
reaper); launchd sidesteps all four. macOS is the only supported
platform.

**Deliverable** (base = emb-107 head):
- `embassy service install`: writes `~/Library/LaunchAgents/
  com.agent-embassy.broker.plist` (owned, mode 0644 as launchd
  requires; the plist contains no secrets) running the exact
  `embassy` binary that ran `install` (`process.execPath` + the
  resolved cli.js path, printed for the user), `RunAtLoad` +
  `KeepAlive` with a throttle, stdout/stderr to `~/Library/Logs/
  agent-embassy/broker.log`, `EMBASSY_STATE_DIR` passed through if
  set; then `launchctl bootstrap gui/$UID <plist>` and prints the
  `embassy health` result. Refuses if a foreground broker holds the
  host lease (names the pid; remedy: stop it first). Idempotent
  (re-install replaces the plist and kickstarts).
- `embassy service uninstall`: `launchctl bootout` + remove the
  plist; `embassy service status`: loaded? pid? last exit status?
  log path.
- `send`/`status` with no broker reachable: one-sentence hint —
  "No broker is running. Run `embassy service install` once, or
  `embassy serve` in a terminal." (replaces the current serve-only
  copy; emb-95's connect-stage classification stays exact).
- Tests: plist rendering snapshot (paths, keys, no env leakage
  beyond EMBASSY_STATE_DIR), refusal when the lease is held (fake
  lease), `launchctl` invocations through an injected runner (no
  real launchctl in tests), the hint on CONTROL_SOCKET_MISSING.
- Docs: README quickstart step 1 becomes `embassy service install`
  (with `embassy serve` as the foreground alternative);
  CONFIGURATION.md service section; cutover runbook uses it on both
  machines; CHANGELOG Unreleased (Added).

**Gate**: light (adversarial read only) — no message-path change.
