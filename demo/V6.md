# Demo v6 — dispatch and receipt

Composition: `EmbassyDemoV6`, 1920×1080, 30 fps, 1,200 frames.

```sh
cd demo
npm ci
npm run check
npx remotion render src/index.ts EmbassyDemoV6 out/embassy-demo-v6.mp4 --codec=h264 --crf=18 --concurrency=4
npx remotion still src/index.ts EmbassyDemoV6 out/poster-v6-full.png --frame=0
```

The light design uses bundled Newsreader, IBM Plex Sans and IBM Plex Mono.
Font files come from Google Fonts' `ofl/newsreader`, `ofl/ibmplexsans` and
`ofl/ibmplexmono` directories; their OFL licenses are alongside the files.
The film makes no network font request. The original Embassy mark paths are
reused, with the outline changed to the design's light-page ink token.

## Recording and deviations

The terminal words are transcribed from fresh interactive Claude/Codex PTY
captures on the installed 4.5.1 broker. Claude sent the prescribed login-flow
question. Codex read a committed, offline dependency-injected login fixture,
identified premature session issuance, and replied through the emitted command.
Both delivery tokens were checked `DELIVERED`. No credentials, usable sessions,
network server or exploit were part of the fixture. The three-sentence answer
and Claude's acknowledgment are genuine; the original no-diff take is excluded.

- Final designer v3 boards are applied: scene 2 shows both recorded pipeline
  rows at 28/40 in a 192 px card; scene 4 is full width and includes the heredoc;
  scene 5 reveals rows during frames 740–800 and scrolls each arriving row within
  the 504 px body, ending on reply, timestamp and acknowledgment. The stamp
  arrives at frame 800. This supersedes the first render's custom scroll.
- Scene 3 keeps Codex's real collapsed command output (`… +4 lines`), rather
  than inventing an expanded tool display. The complete reply appears in scene 5.
- Real spinner wording, elapsed times, ledger ages, heredoc delimiter and
  delivery token replace the draft board's example values. Source line wraps
  are reflowed to the specified card widths; private host suffixes and
  conversation references remain masked.
- Typography deviation: Codex's first quoted row has 97 characters. Its recorded
  wrap is kept, at 28 px, with −0.35 px tracking on quoted rows so it fits the
  1,598 px body without clipping. Other transcript tracking remains unchanged.
- The final overlapping scroll easings settle by frame 800 as specified; the
  last two ease durations shorten to hit that endpoint rather than ending at 807.

Everything else uses the supplied scene boundaries, headline/caption words,
light-page/dark-card palette, grid and type sizes. The SSH scene is explicitly
an illustration, not a claim of a new cross-machine recording.
